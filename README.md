# Logan Noonan — Electrical Engineering Portfolio

Personal portfolio covering electrical building services and power distribution, industrial controls experience, and selected academic and personal electronics projects.

Live site: [l0g4nn.github.io](https://l0g4nn.github.io/).

## Local preview

Run `python3 -m http.server 4173` (or `py -m http.server 4173` on Windows), then open `http://localhost:4173`.

Plain HTML, CSS, and JavaScript; no build step, third-party scripts, fonts, analytics, or package dependencies. GitHub Pages serves the repository root.

The font stack prefers ABC Areal Mono / Areal Mono when installed, with Liberation Mono, Consolas, and Courier New fallbacks. Areal Mono webfont embedding is pending receipt of the owner’s font package from https://abcdinamo.com/free/areal. The official download requires an email address and acceptance of licensing terms and updates; no form has been submitted. No font binaries are bundled.

## Editing

- `index.html`: profile, experience, projects, and inline vector illustrations.
- `styles.css`: responsive layout, design tokens, reduced-motion and print styles.
- `script.js`: mobile navigation and the three engineering-discipline buttons.
- `404.html` and `favicon.svg`: error page and site identity.

Employer names and client details are intentionally omitted. Current professional work is distinguished from academic projects and personal work in development. The illustrations are conceptual, not installation drawings or measured results. The radar project is described as a feasibility study.

The mobile navigation and project disclosures remain usable without JavaScript. No project source-code or contact links should be added without a verified destination.
