Background

I have a BEng (Hons) in Electrical & Electronic Engineering. Before moving into electrical design, I worked in industrial refrigeration controls.

That experience covered PLC programming, HMI / SCADA, plant communications using Modbus and OPC, testing and commissioning support.

Projects

Passive radar for Glasgow airspace

Academic dissertation · Radar & signal processing

I assessed whether an existing over-the-horizon transmission could be used to detect aircraft near Glasgow. The study covered propagation, bistatic geometry, link budgets, matched filtering and pulse integration.

It was a feasibility study, rather than an operational radar system.

Autonomous collection robot

Academic project · ESP32 / C / FreeRTOS

An ESP32 robot combining ultrasonic sensing, steering, motor control and magnetic collection. My work covered embedded control, a FreeRTOS state machine and I²C communication with a separate ESP32-S3 camera unit.

Robot source code on GitHub

FPGA fractal visualisation

Model railway lighting controller

Personal project · STM32 / PCB design · In development

I'm designing a small controller for each model building, using a shared 5 V supply. It combines 3.3 V regulation, MOSFET LED switching, local mode selection and an RS-485 bus.
