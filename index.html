My projects

Some things I've worked on at home and during my degree.

Passive radar for Glasgow airspace

Academic dissertation

A feasibility study into using an existing over-the-horizon transmission to detect aircraft near Glasgow. I looked at propagation, radar geometry, link budgets, matched filtering and pulse integration.

This was a study of a passive bistatic radar concept, rather than an operational tracking system.

* * *

Autonomous collection robot

Academic project

An ESP32-based robot with ultrasonic sensors, steering, motor control and a magnetic collection mechanism. FreeRTOS and a state machine coordinated its movements, with a separate ESP32-S3 camera unit communicating over I²C.

* * *

FPGA fractal visualisation

Academic project

Fractal computation in programmable logic, using Python and Jupyter to control and explore the results.

* * *

Model railway lighting controller

Personal project — in development

A small STM32 controller for each model building, powered from a shared 5 V supply. The design uses 3.3 V regulation, MOSFET LED switching, local mode selection and an RS-485 bus.
