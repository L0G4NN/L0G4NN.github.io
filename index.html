★ Welcome, traveller

Hello! I'm Logan.

I'm an electrical engineer based in Scotland, interested in everything from the systems that power a building to the small bits of code that make a circuit do something useful.

This is my little home on the internet: a place for engineering, electronics, projects, and the occasional tangent.

01. About me

I have a BEng (Hons) in Electrical & Electronic Engineering and work as a graduate electrical engineer. My current focus is electrical building services and infrastructure.

Before moving into electrical design, I gained practical experience in industrial refrigeration controls: PLC programming, operator interfaces, plant communications, testing, and commissioning support.

I like understanding a system from both ends — the calculations and drawings that define it, and the hardware and software that make it work.

03. The project folder

A few things I've spent time building or figuring out. Click a project title for the longer version.

RFPassive radar for Glasgow airspaceAcademic dissertation · Feasibility study

Could an existing over-the-horizon transmission help detect aircraft near Glasgow? I investigated a passive bistatic radar concept using a non-cooperative illuminator.

The study brought together propagation, transmitter–target–receiver geometry, link budgets, matched filtering, and pulse integration. The focus was feasibility and detection constraints, rather than an operational tracking system.

RADAR / SIGNAL PROCESSING / LINK BUDGETS

µCAutonomous collection robotAcademic project · Embedded control

An ESP32-based robot combining ultrasonic sensing, steering, motor control, and a magnetic collection mechanism.

FreeRTOS and an explicit state machine coordinated approach, identification, and collection. A separate ESP32-S3 camera unit communicated over I²C to connect vision with the main controller.

ESP32 / FREERTOS / I²C / ROBOTICS

FPFPGA fractal visualisationAcademic project · Hardware acceleration

Exploring fractal computation in programmable logic, with a Python and Jupyter interface for experimentation.

A useful meeting point between mathematics, hardware architecture, and software: deciding where each part of the work should happen.

FPGA / PYTHON / JUPYTER

LEDModel railway lighting controllerPersonal project · In development

A small controller for each model building, running from shared 5 V power and using an STM32 microcontroller to switch its lighting.

The design brings together 3.3 V regulation, MOSFET LED switching, local mode selection, and an RS-485 bus. The aim is a compact, repeatable way to control lighting across a layout.

STM32 / PCB DESIGN / RS-485 / LEDS
