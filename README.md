# Logan's personal website

A TVA-inspired retro-futuristic engineering portfolio: warm cream and burnt orange, institutional signage, an amber CRT-style illustration, stamped labels and expandable project records. All artwork is original CSS or inline SVG; no external fonts, images or scripts are required.

## Hosting

GitHub Pages serves the root of `main`. No build step, JavaScript or dependencies are required. `.nojekyll` keeps the files as plain static assets.

## Files

- `index.html` — homepage content
- `style.css` — layout, typography and small-screen adjustments
- `background.svg` — legacy background tile retained from the previous design
- `favicon.svg` — orange archive monogram browser icon
- `404.html` — missing-page response

## Content

The homepage leads with current electrical design work, followed by controls experience and concise academic/personal project summaries. Robot and Antichess entries link to their public source repositories.

## Typography and content

The body prefers locally installed ABC Areal Mono or Areal Mono, then system monospace fonts. No commercial font files are bundled. Bold sans-serif headings, responsive layouts, keyboard focus indicators and reduced-motion support are included. Project records use native HTML details/summary controls, with the first record open by default.

Public copy uses Logan's first name only and omits employer and university names. Academic studies and projects in development are labelled accordingly.
