# L0G4NN.github.io

Personal portfolio for Logan, focused on embedded electronics, PCB design, firmware, and practical hardware projects.

## Local preview

```powershell
py -m http.server 4173
```

Then open `http://localhost:4173`.

The site is plain HTML, CSS, and JavaScript with no build step. It is published through GitHub Pages at [l0g4nn.github.io](https://l0g4nn.github.io/).
