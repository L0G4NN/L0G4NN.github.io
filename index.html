001Academic dissertation / Radar & signal processingPassive radar for Glasgow airspace+

I assessed whether an existing over-the-horizon transmission could be used to detect aircraft near Glasgow. The study covered propagation, bistatic geometry, link budgets, matched filtering and pulse integration.

It was a feasibility study, rather than an operational radar system.

  • Bistatic geometry
  • Link budgets
  • Matched filtering
002Academic project / ESP32 · C · FreeRTOSAutonomous collection robot+

An ESP32 robot combining ultrasonic sensing, steering, motor control and magnetic collection. My work covered embedded control, a FreeRTOS state machine and I²C communication with a separate ESP32-S3 camera unit.
